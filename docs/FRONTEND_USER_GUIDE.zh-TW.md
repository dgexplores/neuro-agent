## 系統簡介

### 什麼是 NeuroAgent？

NeuroAgent 是一套基於 AWS Bedrock AI 技術的神經疾病診療輔助系統，專為醫療專業人員設計。本系統提供：

- **智慧診斷建議**：根據病患症狀、病史及生命徵象，提供鑑別診斷建議
- **藥物安全檢查**：檢測多種藥物之間的潛在交互作用
- **醫學影像分析**：上傳 MRI、CT 等影像，取得 AI 分析結果
- **病例管理**：查詢歷史病例，追蹤診療紀錄

### 重要提醒 ⚠️

```
本系統僅供輔助參考，所有診斷建議必須由專業醫師審核。
系統提供的資訊不得取代醫師的臨床判斷。
本系統尚未取得 FDA 或 TFDA 核准，不得直接用於病患照護。
```

### 系統架構

```
使用者介面（您正在使用的前端）
          ↓ HTTPS + JWT 驗證
     AWS API Gateway
          ↓
     AWS Lambda（FastAPI 後端）
          ↓
  Amazon Bedrock（Claude 3 Sonnet AI）
```

## 登入與驗證

### 首次使用

1. **開啟瀏覽器**，前往以下網址：
   - **正式環境**：`https://frontend-8dchdjadv-thc1006s-projects.vercel.app`
   - **本地開發**：`http://localhost:3000`

2. **登入畫面**會顯示以下欄位：
   - 使用者名稱（User ID）
   - 角色（Role）：選擇 `doctor`、`nurse` 或 `researcher`

3. **輸入範例**：
   ```
   使用者名稱：demo-physician
   角色：doctor
   ```

4. **點選「登入」按鈕**後，系統會自動產生 JWT Token 並儲存在瀏覽器中。

### JWT Token 有效期限

- **預設有效期**：24 小時
- **到期後**：系統會自動導向登入頁面，請重新登入
- **安全性**：Token 採用 HS256 加密演算法，符合醫療資訊安全標準

### 手動產生 JWT Token（進階）

如果您需要自行產生 Token：

```python
import jwt
import datetime

payload = {
    'user_id': 'your-user-id',
    'role': 'doctor',
    'exp': datetime.datetime.utcnow() + datetime.timedelta(hours=24),
    'iat': datetime.datetime.utcnow()
}

secret = 'REDACTED'
token = jwt.encode(payload, secret, algorithm='HS256')
print(f"Bearer {token}")
```

## 常見問題排解

### 1. 登入失敗或 Token 無效

**問題**：顯示「401 Unauthorized」或「Token expired」

**解決方法**：
1. 確認您使用的 JWT Token 尚未過期（有效期 24 小時）
2. 重新產生 Token 或重新登入
3. 檢查 Token 格式是否正確（應為 `Bearer eyJ...`）

### 2. 診斷請求逾時

**問題**：等待超過 30 秒仍無回應

**可能原因**：
- AWS Lambda 冷啟動（首次呼叫需要 5-10 秒）
- Bedrock API 暫時延遲
- 網路連線問題

**解決方法**：
1. 重新整理頁面並重試
2. 檢查網路連線
3. 如持續發生，聯繫系統管理員

### 3. 影像上傳失敗

**問題**：「File upload failed」錯誤

**檢查事項**：
- 檔案大小是否超過 10 MB
- 檔案格式是否為支援的格式（JPG、PNG、DICOM）
- 影像檔案是否損毀

### 4. 藥物交互作用檢查顯示「未找到交互作用」

**說明**：
- 系統內建 14 種常見神經科用藥的交互作用資料
- 如果您輸入的藥物不在資料庫中，系統會顯示「未找到相關資料」
- 這不代表藥物之間沒有交互作用，請參考其他藥物資料庫或諮詢藥師

- **支援響應式設計**：可在平板電腦上使用，但不建議手機操作

- **建議頻寬**：10 Mbps 以上
- **延遲**：建議 < 100ms

- **必須啟用 Cookie**：用於儲存驗證 Token
- **必須允許第三方 Cookie**（如使用 AWS API）

## 資料隱私與安全

### HIPAA 相符設計

NeuroAgent 遵循 HIPAA 精神設計：

- **資料加密**：所有資料傳輸使用 HTTPS/TLS 1.2+
- **匿名化**：建議移除可識別個人資訊（如姓名、身分證字號）
- **存取控制**：JWT 驗證機制確保僅授權人員存取
- **資料保留**：DynamoDB 資料 90 天 TTL 自動刪除

### 使用者責任

作為使用者，您應該：

1. **不要**在系統中輸入病患真實姓名
2. **使用**匿名化病例編號（如 `CASE-2025-001`）
3. **定期**更換 JWT Secret Key（建議每 90 天）
4. **登出**時清除瀏覽器快取
