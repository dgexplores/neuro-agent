## 📌 一分鐘快速理解

### NeuroAgent 是什麼？

NeuroAgent 是一套**AI 驅動的神經疾病診療輔助系統**，專為醫療專業人員設計。它就像您的「24/7 神經科專科顧問」，能在數秒內提供：

✅ **鑑別診斷建議**：根據症狀、病史、生命徵象提供前 3 名鑑別診斷
✅ **藥物安全警示**：檢測 14 種常見神經科用藥的危險交互作用
✅ **實證醫學建議**：基於臨床指引的治療方案建議
✅ **風險分層評估**：自動識別高風險因子並提醒追蹤

### 重要免責聲明 ⚠️

```
本系統為輔助工具，所有診斷建議需由專業醫師最終判斷。
系統提供的資訊不能取代您的臨床經驗與判斷。

## 🔬 系統如何運作？（技術原理簡述）

### AI 引擎：Amazon Bedrock Claude 3 Sonnet

NeuroAgent 使用 AWS Bedrock 的 Claude 3 Sonnet 模型，這是目前最先進的醫療 AI 之一：

```
病患資料輸入
      ↓
  結構化處理（Pydantic 驗證）
      ↓
  輸入消毒（防範注入攻擊）
      ↓
  AI 分析（Claude 3 Sonnet）
  • 症狀模式識別
  • 知識庫比對（14 種藥物交互作用、治療指引）
  • 實證醫學推理
      ↓
  信心分數計算（上限 85%）
      ↓
  結構化診斷報告輸出
```

### 為什麼信心分數上限是 85%？

```
醫療 AI 倫理設計：
❌ 95%+ 信心分數 → 醫師可能過度依賴，跳過必要檢查
✅ 85% 上限 → 強制「診斷謙卑」，提醒臨床相關性驗證

實際案例：
某 AI 系統對偏頭痛顯示 98% 信心，導致醫師未安排 CT，
後來病患確診為蜘蛛膜下腔出血。

NeuroAgent 設計理念：
AI 提供「有見地的第二意見」，但最終決策權在醫師手中。
```

### 案例 1：急診室中風快速篩檢

**背景**：台灣某區域醫院急診室，晚間 11 點

**情境**：
- 66 歲男性，家屬報案「講話不清楚、左手無力」
- 急診值班醫師：非神經科專科
- 神經科醫師：on-call 在家（車程 30 分鐘）

**傳統流程**：
1. 急診醫師初步評估（10 分鐘）
2. 電話聯絡神經科醫師（5 分鐘）
3. 等待神經科醫師到院（30 分鐘）
4. 專科評估後安排 CT（15 分鐘）
5. **總耗時：60 分鐘**

**使用 NeuroAgent**：
1. 急診醫師初步評估（10 分鐘）
2. **同步輸入資料至 NeuroAgent（2 分鐘）**
   - AI 診斷：Acute Ischemic Stroke（信心 82%）
   - 建議：立即啟動中風綠色通道、準備 tPA
3. 立即安排 CT（無需等待神經科醫師）（15 分鐘）
4. 電話聯絡神經科醫師並提供 AI 報告（5 分鐘）
5. 神經科醫師抵達時已完成 CT，可直接評估治療
6. **總耗時：32 分鐘（節省 28 分鐘）**

**臨床意義**：
- **時間就是腦神經**：中風黃金治療時間 4.5 小時
- 提前 28 分鐘 = 挽救約 **1.9 億個腦神經元**（估算值）
- 符合台灣腦中風學會「到院 60 分鐘內施打 tPA」指引

## 📚 支援的疾病與藥物

### 神經疾病涵蓋範圍

| 疾病類別 | 具體疾病 | 診斷信心 | 資料來源 |
|---------|---------|---------|---------|
| **頭痛疾病** | 慢性偏頭痛、偏癱型偏頭痛、藥物過度使用頭痛 | 高 | ICHD-3、PubMed |
| **腦血管疾病** | 急性缺血性中風、TIA、腦出血 | 高 | 台灣腦中風學會 |
| **脫髓鞘疾病** | 多發性硬化症（RRMS、SPMS） | 中 | 美國 MS 學會 |
| **癲癇** | 全身性強直陣攣發作、新發癲癇 | 中 | ILAE 指引 |
| **動作障礙** | 帕金森氏症、顫抖症 | 中 | MDS 診斷標準 |
| **周邊神經病變** | 糖尿病神經病變、GBS | 低 | 有限支援 |

### 藥物交互作用資料庫

系統內建 **14 種常見神經科用藥**的交互作用：

**抗凝血/抗血小板藥物**：
- Warfarin（華法林）
- Aspirin（阿斯匹靈）
- Clopidogrel（保栓通）

**抗癲癇藥物**：
- Carbamazepine（卡巴氮平）
- Phenytoin（苯妥英鈉）
- Valproic Acid（丙戊酸）
- Levetiracetam（樂命達）

**帕金森氏症用藥**：
- Levodopa（左旋多巴）
- MAO-B inhibitors（如 Selegiline）

**其他神經科用藥**：
- Ergotamine（麥角胺，偏頭痛急性期用藥）
- Triptans（翠普登類，偏頭痛用藥）
- Amitriptyline（阿米替林，三環抗憂鬱劑）

https://1w80v6fnw1.execute-api.us-east-1.amazonaws.com/prod/

認證方式：
JWT Token（Bearer Token）

主要端點：
• POST /api/v1/diagnosis        - 診斷請求
• POST /api/v1/drug-interactions - 藥物交互作用檢查
• POST /api/v1/upload-image     - 醫學影像分析
• GET  /api/v1/cases            - 病例清單
• GET  /health                  - 健康檢查（無需驗證）
```

### 整合範例（Python）

```python
import requests

# 1. 產生 JWT Token（由 HIS 系統管理）
headers = {
    "Authorization": "Bearer REDACTED",
    "Content-Type": "application/json"
}

# 2. 準備病患資料（從 HIS 系統擷取）
patient_data = {
    "patient_info": {
        "age": 45,
        "gender": "female",
        "medical_history": ["chronic migraine"],
        "current_medications": ["Anti-CGRP antibodies"],
        "allergies": []
    },
    "symptoms": [
        {
            "name": "throbbing headache",
            "severity": "severe",
            "duration_days": 365,
            "description": "One-sided, 13 days/month, severity 9/10"
        }
    ],
    "vital_signs": {
        "bp_systolic": 120,
        "bp_diastolic": 69,
        "heart_rate": 51,
        "temperature": 37.0
    },
    "chief_complaint": "Chronic severe headaches"
}

# 3. 發送診斷請求
response = requests.post(
    "https://1w80v6fnw1.execute-api.us-east-1.amazonaws.com/prod/api/v1/diagnosis",
    headers=headers,
    json=patient_data
)

# 4. 處理回應
if response.status_code == 200:
    result = response.json()
    print(f"診斷：{result['diagnosis'][0]['condition']}")
    print(f"信心分數：{result['diagnosis'][0]['confidence']}")
else:
    print(f"錯誤：{response.status_code}")
```

## ❓ 常見問題（FAQ）

### Q1：NeuroAgent 可以取代神經科醫師嗎？

**A**：不能。NeuroAgent 的定位是「輔助工具」，而非「替代醫師」。

```
適用情境：
✅ 急診室初步鑑別診斷（提供方向）
✅ 基層診所專科諮詢（彌補專科醫師不足）
✅ 年輕醫師學習輔助（教學工具）
✅ 藥物安全檢查（減少處方錯誤）

不適用情境：
❌ 直接向病患提供診斷（違反醫師法）
❌ 複雜病例的最終診斷（需專科醫師）
❌ 醫療糾紛的法律責任歸屬（仍由醫師負責）
```

---

### Q2：診斷準確度如何驗證？

**A**：NeuroAgent 使用真實醫學文獻驗證：

```
測試資料來源：
• PubMed Central（NIH 資料庫）
• Frontiers in Neurology（2024 期刊）
• University of Utah Medical Library
• 台灣醫學期刊

驗證方法：
1. 輸入文獻中的病患資料（症狀、病史、檢查）
2. 比對 AI 診斷與文獻最終診斷
3. 評估首選診斷正確率與前三名包含率

結果：
✅ 首選診斷正確：83%（5/6 cases）
✅ 前三名包含正確診斷：100%（6/6 cases）
```

---

### Q3：如何處理 AI 診斷錯誤的情況？

**A**：系統設計有多層安全機制：

```
安全機制 1：信心分數上限 85%
• 強制醫師進行臨床相關性驗證
• 避免過度信任 AI 輸出

安全機制 2：強制包含危險鑑別診斷
• 即使機率低，仍會列出「需排除」的嚴重疾病
• 例如：頭痛病患會提示「顱內腫瘤（需排除）」

安全機制 3：明確免責聲明
• 每份報告都附帶「需專業醫師最終判斷」聲明
• 提醒醫師這是輔助工具，非確診系統

臨床實務建議：
1. 將 AI 建議視為「初步假設」
2. 結合理學檢查、影像學確認
3. 如 AI 診斷與臨床不符，以臨床判斷為準
4. 記錄 AI 建議供後續學習改進
```

### Q5：病患資料會保存多久？

**A**：90 天後自動刪除（DynamoDB TTL）。

```
資料保留政策：
• 病例資料：90 天自動刪除
• 影像資料：上傳後 90 天自動刪除（S3 Lifecycle Policy）
• 系統日誌：7 天自動刪除（CloudWatch Logs）

為何 90 天？
• 符合「最短必要保留期限」原則
• 足夠追蹤急性期病患（大多數神經疾病追蹤 < 3 個月）
• 減少長期儲存的隱私風險

如需長期保留：
建議匯出為 PDF 儲存於醫院病歷系統
```
